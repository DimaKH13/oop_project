# OOP Project

Учебный проект для демонстрации принципов объектно-ориентированного программирования (ООП) на примере интернет-магазина.

## Описание
Реализованы классы `Product` (товар) и `Category` (категория товаров). 
Класс `Category` ведет автоматический подсчет общего количества созданных категорий и товаров в них с помощью атрибутов класса `category_count` и `product_count`.
